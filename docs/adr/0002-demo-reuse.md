# ADR 0002: Reuse from the old demo

- Status: accepted
- Date: 2026-09-26
- Chunk: 0

## Context
Chunk 0 asks for a reconciliation of `docs/demo/` and `docs/research/` against the
architecture. At the time of this chunk `docs/demo/` is empty: the founder has not located the
old demo. `docs/research/` holds the two documents written during planning and nothing else.

## Decision
Nothing is reused from the demo because nothing was available. No contradiction between
`docs/research/` and `docs/ARCHITECTURE.md` was found, since both were written together.

## Consequences
If the demo is found later, add it to `docs/demo/` and supersede this ADR with a list of what
is reused (files named) and what is discarded. Do not reuse anything without an ADR.
